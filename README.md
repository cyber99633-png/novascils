# NOVA SKILLS

مكتبة مهارات عملية لوكلاء الذكاء الاصطناعي وأدوات التطوير. تهدف إلى توفير ملفات مهارات قابلة للتنفيذ والتحقق والصيانة.

## الأهداف
- مهارات فعلية وليست أسماء تصنيفية فقط.
- تنظيم حسب المجال والتخصص.
- تغطية البرمجة والتصميم والذكاء الاصطناعي والأتمتة والاختبار والأمن السيبراني الدفاعي.
- تضمين أمثلة ومعايير تحقق عند الحاجة.
- احترام التراخيص والخصوصية والأمان.

## البنية
- `CATEGORIES.md`: المجالات المعتمدة.
- `QUALITY_STANDARD.md`: معيار قبول المهارات.
- `templates/SKILL_TEMPLATE.md`: قالب إنشاء مهارة.
- `skills/`: ملفات المهارات الفعلية.

## الحالة
هذه بنية تأسيسية. ستضاف المهارات تدريجياً بعد إعدادها والتحقق منها؛ أسماء التصنيفات وحدها ليست مهارات مكتملة.
